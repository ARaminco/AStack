# نمونه‌های او‌سی‌آر پیشرفته

## نمونه درخواست
- وقتی PDF لایه متنی ندارد یا لایه متنی آن قابل اعتماد نیست.

## نمونه فراخوانی
```
astack ask "PDF لایه متنی ندارد یا لایه متنی آن قابل اعتماد نیست"
astack skill show document-ocr
```

## نمونه خروجی مورد انتظار
- متن استخراج‌شده به تفکیک صفحه
- فیلدهای کلیدی به‌صورت داده ساخت‌یافته
- جدول‌ها در قالب CSV
- گزارش اطمینان و فهرست نواحی مشکوک
- مسیر فایل‌ها و ارجاع صفحه برای هر مقدار
