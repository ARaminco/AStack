# Learned Skills

Skills in this directory are generated by the learning engine from repeated real
work. They are preserved across upgrades and never overwritten by the AStack core.

- inspect: `astack skill list --source learned`
- validate: `astack skill test <id>`
- promote: `astack skill promote <id> --status active`
- roll back: `astack skill rollback <id> <version>`

A pattern becomes a skill only after it has been done at least three times, on at
least two different days, with a good success rate. Thresholds live under
`learning:` in `astack.config.yaml`.
