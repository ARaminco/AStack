# نمونه‌های طراحی تصویر

## نمونه درخواست
- وقتی برای کمپین، شبکه اجتماعی، ارائه یا سند رسمی به تصویر نیاز است.

## نمونه فراخوانی
```
astack ask "برای کمپین، شبکه اجتماعی، ارائه یا سند رسمی به تصویر نیاز است"
astack skill show image-design
```

## نمونه خروجی مورد انتظار
- جهت‌گیری هنری مکتوب
- سه گزینه با توضیح تفاوت‌ها
- فایل نهایی و نسخه‌های کانال‌ها
- چک‌لیست کیفیت تکمیل‌شده
- مسیر فایل‌ها و نسخه‌بندی
