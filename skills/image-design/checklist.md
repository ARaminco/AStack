# چک‌لیست طراحی تصویر

- [ ] خلاصه سفارش را بساز
- [ ] جهت‌گیری هنری را قبل از تولید بنویس
- [ ] برای دارایی‌های قطعی و متن‌دار — لوگو، نمودار، بنر با متن دقیق — اول SVG بساز
- [ ] برای تصویرهای مفهومی از سرویس تولید تصویر پیکربندی‌شده با `credential
- [ ] همیشه سه گزینه با تفاوت معنادار تولید کن، نه سه نسخه از یک ایده.
- [ ] متن روی تصویر را پس از تولید بازبینی کن
- [ ] نسخه‌های مورد نیاز کانال‌ها را بساز (مربع، عمودی، افقی) و ناحیه امن هر کانال را رعایت کن.
- [ ] چک‌لیست کیفیت را اجرا کن
- [ ] فایل نهایی را با نام‌گذاری قابل ردیابی ذخیره کن و نسخه‌ها را نگه دار.
- [ ] تصویرهای تولیدشده برای استفاده رسمی را با ذکر منبع و تاریخ در حافظه پروژه ثبت کن.
- [ ] کنترل کیفیت اجرا شد
- [ ] تجربه با `astack learn record` ثبت شد
