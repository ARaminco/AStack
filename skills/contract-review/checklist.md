# چک‌لیست بازبینی قرارداد

- [ ] نوع قرارداد، طرفین، موضوع، مدت و قانون حاکم را استخراج کن.
- [ ] تعهدهای هر طرف را با مهلت و شرط اجرا فهرست کن.
- [ ] بندهای پرریسک را بررسی کن
- [ ] برای هر ریسک، شدت و احتمال را بنویس و بند جایگزین پیشنهاد بده.
- [ ] تناقض‌های داخلی و ارجاع‌های شکسته به پیوست‌ها را پیدا کن.
- [ ] اگر نسخه قبلی وجود دارد، تفاوت‌های معنایی را جدا از تغییرات نگارشی گزارش کن.
- [ ] بندهای غیرقابل اجرا یا مغایر با قانون حاکم را علامت بزن.
- [ ] خلاصه تصمیم را بنویس
- [ ] کنترل کیفیت اجرا شد
- [ ] تجربه با `astack learn record` ثبت شد
