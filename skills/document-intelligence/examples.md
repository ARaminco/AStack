# نمونه‌های هوش اسناد

## نمونه درخواست
- وقتی باید از یک قرارداد، صورت مالی، رأی یا گزارش بلند پاسخ گرفت.

## نمونه فراخوانی
```
astack ask "باید از یک قرارداد، صورت مالی، رأی یا گزارش بلند پاسخ گرفت"
astack skill show document-intelligence
```

## نمونه خروجی مورد انتظار
- پاسخ کوتاه با ارجاع
- نقشه بخش‌های مرتبط
- تعهدها و مهلت‌های استخراج‌شده
- ابهام‌ها و تناقض‌ها
- به‌روزرسانی گراف دانش
