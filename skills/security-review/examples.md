# نمونه‌های بازبینی Security

## نمونه ۱
**درخواست:** security-review را روی تغییر فعلی اجرا کن و روی `OWASP Top 10` تمرکز کن.

**پاسخ مورد انتظار:** گزارشی که فایل‌های اثرپذیر، دلیل اهمیت موضوع، راه‌حل کم‌ریسک و commandهای verification را مشخص کند و از سیاست زبان مرکزی پیروی کند.

## نمونه ۲
**درخواست:** security-review را همراه با `security-review` و `testing-review` اجرا کن.

**پاسخ مورد انتظار:** یافته‌ها جداگانه و بدون تکرار برای correctness، security و test coverage نوشته شوند.

## نمونه ۳
**درخواست:** اگر evidence کافی نیست، قبل از نتیجه‌گیری فرضیات را شفاف کن.

**پاسخ مورد انتظار:** سوال‌ها و اصطلاحات طبق `../../system/language-policy.md` نوشته شوند.
