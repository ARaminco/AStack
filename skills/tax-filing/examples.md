# نمونه‌های تنظیم اظهارنامه مالیاتی

## نمونه درخواست
- در سررسید دوره‌های مالیاتی.

## نمونه فراخوانی
```
astack ask "در سررسید دوره‌های مالیاتی"
astack skill show tax-filing
```

## نمونه خروجی مورد انتظار
- کاربرگ محاسبه با ارجاع اسناد
- نتیجه کنترل‌های تطبیقی
- تصویر فرم پیش از ارسال
- رسید و شماره پیگیری
- بایگانی دوره و یادداشت‌های دوره بعد
