# چک‌لیست اپراتور وب

- [ ] هدف را دقیق بنویس و مشخص کن کدام گام برگشت‌ناپذیر است (ارسال، پرداخت، حذف).
- [ ] پروفایل مرورگر مناسب را انتخاب کن
- [ ] قبل از اجرا، نقشه گام‌ها را با `astack browser run --dry-run` بساز و به مالک نشان بده.
- [ ] گام‌های خواندنی را اجرا کن، وضعیت واقعی صفحه را استخراج کن و از حدس‌زدن ساختار صفحه بپرهیز.
- [ ] فرم را پر کن و پیش از ثبت، اسکرین‌شات وضعیت را به‌عنوان شاهد ثبت کن.
- [ ] در گام برگشت‌ناپذیر متوقف شو، خلاصه دقیق مقادیر واردشده را گزارش کن و منتظر تأیید مالک بمان.
- [ ] پس از تأیید، اجرا را از همان نقطه ادامه بده
- [ ] بعد از ثبت، نتیجه را مستقل راستی‌آزمایی کن
- [ ] همه شواهد را در بسته شواهد پرونده ثبت کن و یکپارچگی زنجیره را بررسی کن.
- [ ] اگر انتخاب‌گرها تغییر کرده‌اند، مسیر جدید را ثبت کن تا skill مربوط به‌روزرسانی شود.
- [ ] کنترل کیفیت اجرا شد
- [ ] تجربه با `astack learn record` ثبت شد
