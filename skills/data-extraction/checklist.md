# چک‌لیست استخراج داده ساخت‌یافته

- [ ] طرح داده را اول تعریف کن
- [ ] یک نمونه را دستی استخراج کن و با مالک تأیید بگیر، سپس روی کل مجموعه اجرا کن.
- [ ] برای هر رکورد منبع را ثبت کن
- [ ] قواعد اعتبارسنجی را اجرا کن
- [ ] رکوردهای مشکوک را جدا کن و هرگز آن‌ها را با مقدار حدسی پر نکن.
- [ ] خروجی را در CSV با کدگذاری UTF-8 و جداکننده اعلام‌شده بنویس و نسخه JSON را برای مصرف ماشینی کنار آن بگذار.
- [ ] برای مغایرت‌گیری، کلید تطبیق را مشخص کن و تفاوت‌ها را در سه دسته گزارش کن
- [ ] گزارش پوشش را بده
- [ ] کنترل کیفیت اجرا شد
- [ ] تجربه با `astack learn record` ثبت شد
