# نمونه‌های استخراج داده ساخت‌یافته

## نمونه درخواست
- وقتی مجموعه‌ای از فاکتورها، صورت‌حساب‌ها یا فرم‌ها باید به جدول تبدیل شود.

## نمونه فراخوانی
```
astack ask "مجموعه‌ای از فاکتورها، صورت‌حساب‌ها یا فرم‌ها باید به جدول تبدیل شود"
astack skill show data-extraction
```

## نمونه خروجی مورد انتظار
- طرح داده
- فایل CSV و JSON
- گزارش اعتبارسنجی
- فهرست رکوردهای مشکوک با ارجاع
- گزارش مغایرت در صورت وجود دو منبع
