# چک‌لیست بستن دوره مالی

- [ ] دامنه دوره را مشخص کن
- [ ] کامل‌بودن داده را بررسی کن
- [ ] مغایرت‌گیری بانکی را انجام بده و هر تفاوت را به یک علت مشخص نسبت بده.
- [ ] حساب‌های دریافتنی و پرداختنی را سن‌بندی کن و اقلام قدیمی را علامت بزن.
- [ ] اسناد اصلاحی را با شرح، مبلغ، حساب و مستند پشتیبان تنظیم کن.
- [ ] تراز آزمایشی را بگیر و توازن را بررسی کن
- [ ] نسبت‌های کلیدی را با دوره قبل مقایسه کن و انحراف‌های معنادار را توضیح بده.
- [ ] گزارش بستن را بنویس و اقلام باز را برای دوره بعد فهرست کن.
- [ ] تصمیم‌های حسابداری را با `astack memory remember --facet decision` ثبت کن.
- [ ] کنترل کیفیت اجرا شد
- [ ] تجربه با `astack learn record` ثبت شد
