# AStack Documentation

AStack is a personal AI operating system for any practice — software, legal, finance, tax, accounting, marketing, operations, HR, research, and business. It organizes domains, teams, agents, reusable skills, professional roles, workflows, memory, configuration, localization, browser guidance, plugins, tests, and scripts into a Markdown-first project that AI agents can operate.
