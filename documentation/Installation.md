# Installation

## Local Use
```bash
npm install
npm test
node bin/astack.mjs /review
```

No package dependencies are required in the first localized scaffold.

## Agent Use
Point Claude Code, OpenAI Codex, ChatGPT, or another agent at this repository and ask it to load `astack.config.yaml`, `system/language-policy.md`, the relevant workflow, and the relevant skill files.
